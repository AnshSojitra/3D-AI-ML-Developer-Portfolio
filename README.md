# 3D-AI-ML-Developer-Portfolio

Interactive 3D developer portfolio for an AI/ML engineer, built with **React + TypeScript**, **React Three Fiber/Three.js**, and **Tailwind CSS**.

## Features

- Interactive hero canvas with a rotating neural-network style 3D graph
- About, Skills, Featured Projects, Experience/Research timeline, and Contact sections
- Project cards with tags, architecture summaries, live demo links, and GitHub links
- Dark-mode neon/cyan + purple glassmorphism styling
- Smooth-scroll navigation and scroll reveal animations
- Responsive, modular component structure

## Tech Stack

- React + TypeScript + Vite
- Three.js + @react-three/fiber + @react-three/drei
- Tailwind CSS

## Local Development

```bash
npm install
npm run dev
```

## Validation

```bash
npm run lint
npm run build
```
